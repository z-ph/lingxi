# 30 秒演示：在笔记里选中、复制、粘贴

[简体中文](demo.md) | [English](en/demo.md)

状态：M0 已定义（issue #1）。录制本身是 M1 的验收产物；本文给出任务、脚本和录制方案。

## 1. 任务

**提示词**（输入到一个全新的 Agent 会话）：

> 打开 Markor 里的 `demo.md`，滑到笔记末尾。长按选中最后一句，拖动选择范围，复制。打开
> `paste.md`，把内容粘贴进去，再输入一句 `Copied by the agent.`。只能用本项目的工具。
> 不要发送、拨打电话、支付或删除任何东西。

**参考配置**

| 项目 | 参考 | 说明 |
| --- | --- | --- |
| 手机 | Pixel 6a，Android 14 | 任何真 Android 手机；本演示只覆盖 Android |
| 笔记 App | 来自 F-Droid 的 Markor 2.x，本地、免账号 | 或设备自带的笔记 App；必须无需账号 |
| 笔记内容 | `demo.md` 是一段公开的英文全字母句集合；`paste.md` 为空 | 由 Agent 在录制前创建 |
| Agent | Claude Code / Cursor / DSH，通过本项目的局域网 MCP 接入 | Agent 和模型版本写进视频简介 |

**平台范围**：本演示只覆盖 Android。iOS 不在当前项目范围：iOS 没有等价的公开无障碍接口，
README 已把 iOS 列为非目标；如果以后要支持 iOS，需要另立 issue 和单独的演示方案。

**准备状态**（Agent 在录制前完成，不计入 30 秒）：

- 在 Markor 里创建 `demo.md`，写入 20-25 行公开的英文全字母句（例如
  `The quick brown fox jumps over the lazy dog.` 等），保存；再创建空的 `paste.md`。
- 打开 `demo.md` 并停在顶部；确认 `paste.md` 出现在文件列表。
- 启动手机录屏和笔记本轨迹录制；清空通知和剪贴板。
- 操作者只需启动 Agent 会话；不需要拍摄、举牌或触碰手机。

**步骤（Agent 做什么）**

1. `launch_app(package="net.gsantner.markor")`，`wait_for` 编辑器。
2. `swipe` 从下往上，滚动到 `demo.md` 末尾。
3. `screenshot` / `ui_tree` 定位最后一句。
4. 长按最后一句：用原地、约 800ms 的 `swipe` 模拟长按（如果 daemon 支持 `tap` 的 hold
   参数，则用 `tap`）。
5. `swipe` 拖动选区手柄，把选择范围扩到最后一句的结尾（按住拖动）。
6. `tap` 上下文菜单里的 Copy。
7. `tap` 返回文件列表，打开 `paste.md`。
8. 长按编辑器，`tap` Paste。
9. `type("Copied by the agent.")`，保存。
10. `screenshot` 核对 `paste.md` 的内容与 `demo.md` 中被选中的句子一致。

**预期结果**：`paste.md` 包含从 `demo.md` 复制过来的最后一句，加上 `Copied by the agent.`；
录屏中能看到滚动、长按、拖动选区、复制和粘贴。

**成功判定**：`paste.text` 包含 `demo.selected_text`，且 `demo.selected_text` 与 `demo.md`
的最后一句一致。

**为什么选这个任务**

目标是让 Agent 像人一样在手机上完成一段多步文本操作，而不是只点一下：

- **基本操作齐全**：滑动、长按、拖动、复制、粘贴、输入，一次演示全部覆盖。
- **无实体道具**：不需要卡片、支架、外部相机、灯光或拍手；屏幕录制即可。
- **人工任务少**：Agent 准备笔记、启动录制、合成视频；人只启动会话。
- **真实 App**：Markor 是真实、免账号的笔记 App；录屏展示真实 Android 界面。
- **30 秒可行**：约十次工具调用；笔记预置，录制只做操作。
- **可复现**：任何 Android 手机、一个免账号笔记 App、一段公开文本。
- **隐私安全**：不接触账号、消息、支付或个人内容。

**考虑过的替代方案**

| 候选 | 为什么不适合 |
| --- | --- |
| 相机读卡片 | 需要实体卡片、外部拍摄或真人摆卡；评审意见明确不需要，屏幕录制即可。 |
| 设置里拖动亮度 + 读设备信息 | 覆盖滑动和拖动，但缺少长按、选中、复制/粘贴，成功判定也较弱。 |
| 发微信 / 短信 | 需要账号和隐私数据；发送是 M2 的危险动作门禁。 |
| 计算器算随机算式 | 只覆盖点击和输入，缺少滑动、拖动、选中。 |
| 浏览器读随机码 | 需要本地页面、书签等额外准备，人的任务反而更多。 |

## 2. 脚本（硬上限 30 秒）

**Agent** = 笔记本上显示、并由笔记本实时 TTS 朗读的台词。**手机** = 手机屏幕上的动作。
**观众** = 手机录屏 + 笔记本轨迹画中画。

| 时间 | Agent 说 | 手机做什么（本项目工具） | 观众看到 |
| --- | --- | --- | --- |
| 0:00 | （屏幕显示提示词）“滑到笔记末尾，选中最后一句并复制到另一个笔记。” | 停在 `demo.md` 顶部 | 手机录屏：Markor 长笔记；画中画：Agent 会话 |
| 0:02 | “先滑到末尾。” | `swipe` 上滑 | 笔记滚到底部；轨迹显示 `swipe` |
| 0:05 | “长按选中最后一句。” | 原地长按（slow `swipe`） | 出现选区手柄；轨迹显示长按 |
| 0:08 | “把选区拖到句尾。” | `swipe` 拖动选区手柄 | 最后一句被完整选中；轨迹显示拖动 |
| 0:11 | “复制。” | `tap` Copy | 系统复制菜单；选区高亮 |
| 0:13 | “打开 paste.md。” | `tap` 返回；`tap` `paste.md` | 文件列表和空白编辑器 |
| 0:16 | “粘贴。” | 长按编辑器；`tap` Paste | 复制的句子出现在 `paste.md` |
| 0:19 | “补一句说明。” | `type("Copied by the agent.")` | 后缀出现在笔记里 |
| 0:22 | “核对完成。” | `screenshot` | 笔记内容与源句一致 |
| 0:26 | “把你的手机，变成 Agent 的工具。” | - | 片尾标题；手机录屏结束 |

时间是目标，不要求逐帧精确。最终成片不超过 30.0 秒，动作保持实时；如果录制超时，缩短 Agent
的台词或减少口播，绝不放快画面。

**操作者只做这些**：启动 Agent 会话；如果手机录屏第一次需要授权，点一次允许。其余由 Agent
完成；0:00 到 0:26 之间不碰手机。

**意外情况**

- 长按没有触发选择：改用 `tap` 的 hold 参数，或再长按 200ms。
- 选区手柄拖不动：改用手势 `swipe` 从选区末端拖到句尾；仍不行就选中整段。
- Markor 的复制/粘贴菜单不同：用系统剪贴板的 Copy/Paste，或 `observe(clipboard)` 核对。
- 录屏启动失败：用 daemon 的截图流，Agent 合成视频；不要让人拿手机拍摄。
- 文件列表里找不到 `paste.md`：用 Markor 的新建笔记按钮创建。

## 3. 录制方案

### 3.1 录制源

- **手机录屏（主画面）**：Agent 通过下拉快捷设置启动手机自带录屏，或在 daemon 提供录屏/
  截图流时用后者。录屏包含状态栏、Markor 界面和点击/滑动轨迹（如果系统开启“显示点按操作”）。
- **取回**：如果使用手机自带录屏，Agent 通过系统分享到笔记本的本地 HTTP 服务取回文件；
  如果 daemon 提供截图/录屏流，则直接使用，无需取回。
- **笔记本轨迹（画中画）**：Agent 在笔记本上启动 OBS 或终端录制，画面包含 MCP 工具调用和
  参数；作为右下角画中画。
- **合成**：Agent 用 ffmpeg 把手机录屏和轨迹画中画合成 1920x1080、30fps、H.264、AAC
  48kHz、不超过 30.0 秒的成片；保留原始录屏。
- **同步**：手机状态栏时钟和轨迹时间戳对齐；不剪切动作，不加速；只在首尾裁剪。
- **不需要**：外部相机、三脚架、灯光、拍手、实体手机入镜。

### 3.2 音频与语言

- 笔记本 TTS 实时朗读 Agent 台词，由笔记本麦克风或系统音频录制；不做后期配音。
- 手机录屏不依赖麦克风；如果录屏包含触摸音，保留。
- 英语配音 + 英文硬字幕 + 中文字幕轨；中文配音版可复用同一录屏。

### 3.3 导出

- 1920x1080，30fps，H.264，AAC 48kHz，不超过 30.0 秒。
- 清除元数据；不发布原始录屏以外的个人内容。

### 3.4 录制前检查

- [ ] 手机只连 Wi-Fi；没有 USB/ADB/scrcpy。
- [ ] 专用演示设备/用户；没有个人账号、通知、聊天或剪贴板内容。
- [ ] `demo.md` / `paste.md` 已准备；Markor 打开 `demo.md` 顶部。
- [ ] 手机录屏已授权并启动；笔记本录制已启动；已回看 5 秒测试片段。
- [ ] 显示点按操作已开启；亮度足够。
- [ ] 令牌、局域网 IP、二维码不在录屏/轨迹画面内或已打码。

## 4. 视频如何证明这是真机

- 录屏展示真实 Android 状态栏、Markor 界面、系统选择/复制/粘贴菜单；模拟器可以模仿界面，
  但不能证明真实触摸和系统剪贴板行为。
- 视频简介记录手机型号、Android 版本、Markor 版本、网络、Agent/模型版本；可选在录屏开头
  展示 `设置 > 关于手机` 的型号/版本（遮住 IMEI 和序列号）。
- 原始录屏保留；成片只做首尾裁剪和画中画合成，不重排动作。
- 轨迹与屏幕一致：`swipe` 对应滚动/拖动，`tap` 落在 Copy/Paste，`type` 对应后缀。
- **局限**：屏幕录制比外部相机拍摄弱；本项目按所有者的方向以录屏为准，不声称录屏能独立
  证明物理设备。需要更强证明时，后续可加一段可选的实拍，不作为本演示的要求。
- 无 USB/ADB/模拟器；Agent 通过局域网 MCP 操作手机。

## 5. 隐私

- **专用演示手机/笔记本**：没有个人账号、联系人、消息、通话记录、照片、笔记或文件；飞行
  模式并开启 Wi-Fi；没有锁屏通知；不插 SIM 卡或用仅数据演示卡。
- **公开文本**：`demo.md` 只包含公开的英文全字母句；不包含姓名、号码、地址、链接或凭据。
- **录屏范围**：只包含 Markor 和（可选的）设置页面；不录通知、聊天、浏览器标签或 shell
  历史。
- **打码/移出画面**：令牌、局域网 IP、二维码、设备序列号和 IMEI、账号邮箱和头像。
- **剪贴板**：录制前清空；录制后清空。
- **后期**：发布前逐帧审查；需要打码的每一帧都处理；清除元数据；演示设备之后擦除或轮换。
- **不做危险动作**：不发送、不打电话、不支付、不删除、不改账号；发消息演示留给 M2 的
  确认门禁。
