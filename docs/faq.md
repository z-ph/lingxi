# 常见问题

[简体中文](faq.md) | [English](en/faq.md)

## 需要 root 或开发者模式吗？

不需要。Phone as Tool 走 Android 无障碍服务，在系统设置里启用该服务即可；它不依赖 USB 或 ADB
调试，因此不要求 root 或开发者模式。控制端 Agent 通过局域网 MCP 连接手机。

## 数据会离开手机吗？

默认不会。屏幕、像素和数据留在手机；只有 Agent 明确请求的内容（例如截图或界面树）才出设备，
审计日志本地保存、可导出、不上传。项目不是云托管服务，用你自己的手机不需要注册账号。

## 支持哪些 Android 版本？

目前只支持 Android；iOS 是明确的非目标，因为没有对等的公开无障碍接口。具体的最低 Android
版本尚未确定，现阶段也还没有可用版本。
